A free, bilingual, web-based 3D anatomy atlas for interactive study and self-assessment, making medical education accessible to everyone.

Language Barrier

Most resources are English-only, limiting access

Limited Progress Tracking

No way to monitor learning progress or save notes

Our Solution

Browser-based 3D viewer + Arabic/English content + progress tracking + personal notes

Progress Sync Across Pages

Resolved

localStorage + device-common.js

Keeping progress consistent across 5 separate HTML pages (Skeletal, Muscular, Circulatory, Digestive, Nervous) was a major challenge. We solved it by creating a shared JavaScript module that syncs studied organs and notes automatically.

Shared device-common.js module
Real-time progress bar updates
Persistent notes across sessions
DifficultyHigh

Responsive RTL + LTR Layout

Resolved

Bidirectional CSS

Designing a layout that works for both Arabic (RTL) and English (LTR) without breaking Bootstrap components was tricky. Text alignment, margins, and flex directions had to be carefully managed.

Bootstrap RTL integration
Custom CSS overrides for margins
Both languages fully supported
DifficultyMedium
